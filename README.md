# somethinglikets

Standalone personal website.

## Pages
- Home
- About
- Interests
- Favorites
- Memories — intentionally empty until real memories are added
- Timeline
- Quotes
- Music — custom player using the supplied MP3
- Birthday — dedicated birthday page using the two supplied birthday images

## Interaction
Every page has a clear action button for moving through the site, and the mobile navigation includes a dedicated Birthday page.

## Birthday assets
The birthday page uses the two images supplied in the conversation.

## Run
Open `index.html` in a browser, or serve the folder with a simple static web server.
